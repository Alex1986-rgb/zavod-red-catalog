# Завод Редукторов (каталог) — Обзор

Статический сайт-каталог промышленных редукторов и мотор-редукторов (демо-редизайн боевого zavod-red.ru).
Чистый HTML/CSS/JS без сборки, изображения и данные встроены. Публикуется через GitHub Pages из ветки `main`.
Живая демонстрация: https://alex1986-rgb.github.io/zavod-red-catalog/

## Стек и структура

- **Фронтенд:** статические `*.html` в корне (каждая страница — самостоятельный файл), ванильный JS, без сборки и зависимостей.
- **Ассеты:** всё в `assets/` — скрипты (`site.js` и `*-mount.js`), стили (`podbor.css`), данные (`podbor-data.json`, ~390 КБ), медиа (webp/mp4/svg), иконки.
- **Инструменты:** `tools/gen_images.py` — генерация фото через Replicate (Python, отдельно от сайта).
- **Деплой:** `.github/workflows/pages.yml` — GitHub Pages при push в `main`. `.nojekyll` отключает Jekyll.
- `.claude/` в `.gitignore` (локальная конфигурация, в репозиторий не коммитится).

## Как запускать

Локальный сервер (из `.claude/launch.json`, конфиг `zr-cat`, порт 8090):

```bash
python3 -m http.server 8090 --directory /Users/alexandr/projects/zavod-red-catalog
```

Открыть http://localhost:8090/. Прод разворачивается автоматически GitHub Actions при push в `main`.

## Ключевые файлы

- `index.html` — главная (герой с видео-фоном, ~126 КБ, самый крупный HTML).
- `catalog.html` — каталог с фильтрами-чипами; `product.html` — карточка товара.
- `podbor.html` + `assets/podbor.js` + `assets/podbor-data.json` — подбор по параметрам (данные в JSON).
- `calculator.html` — калькулятор стоимости; `shildik.html` — подбор по шильдику/фото.
- `assets/site.js` — общий интерактив (FAQ, вкладки, корзина, тема, тосты); данные макета захардкожены внутри.
- `assets/*-mount.js` — монтирование конкретных страниц (cart, cabinet, checkout, hero, podbor).
- `tools/gen_images.py` — пакетная генерация фото редукторов через Replicate/FLUX (нужен `REPLICATE_API_TOKEN`).
- `.github/workflows/pages.yml` — деплой на GitHub Pages; `sitemap.xml`, `robots.txt`, `404.html` — SEO/служебные.
- `AI-STACK.md` — памятка по AI-инструментам проекта.

## Рабочие принципы (AI-агенты)

- Гигиена контекста: чем меньше в контексте, тем точнее модель. Большую задачу дроби на тикеты, каждый — в чистом контексте.
- Цикл разработки: `/grill-with-docs` → `/to-spec` → `/to-tickets` → `/implement` → `/code-review` (глобальные скиллы).
- Субагенты — в `.claude/agents/`, оркестраторы-стадии — в `.claude/commands/`. Инструмент, не вписанный в инструкцию агента, агент не использует.
- Память проекта — скилл `llm-wiki` (index.md → entities/ → concepts/). Мультиагентные системы — скилл `agentic-system`.

## Подводные камни

- **Нет сборки.** Каждая `*.html` правится напрямую; общей вёрстки-шаблона нет — одинаковые правки (шапка, футер, meta) нужно дублировать по всем страницам.
- **Данные захардкожены.** FAQ, реквизиты компании и т.п. вшиты прямо в `assets/site.js`; часть каталога — в `assets/podbor-data.json`. Ищи по строке, а не по «модели данных».
- **`.claude/` не в репозитории** (`.gitignore`). Директории `agents/`/`commands/` из принципов выше нужно создавать локально — по факту сейчас в `.claude/` только `launch.json`.
- **MCP не активны по умолчанию.** Firecrawl/Exa включаются копированием `.mcp.json.example` → `.mcp.json` и требуют своих API-ключей (`FIRECRAWL_API_KEY`, `EXA_API_KEY`).
- **Генерация фото стоит денег и вне сайта.** `tools/gen_images.py` шлёт запросы в Replicate; результаты кладёт в `assets/generated/` (сейчас там пусто — лучшие варианты выбираются вручную).
- **SEO-ограничения.** По истории коммитов держат title ≤65 и description ≤160 символов — при правке meta соблюдать.
- **Деплой из корня.** Workflow заливает всю папку (`path: "."`) на Pages — лишние/временные файлы в корне попадут в прод.

## Рабочие процессы Claude Code

- **Параллельные сессии**: `claude --worktree <имя>` — отдельная копия репозитория на своей ветке; две задачи в двух терминалах, правки не сталкиваются. Локальные файлы вне гита, нужные для работы, перечислены в `.worktreeinclude` — они копируются в worktree автоматически.
- **План перед правками**: `Shift+Tab` до режима `plan` (или `claude --permission-mode plan`) — Claude сначала предлагает план и не трогает файлы до одобрения. Полезно для рискованных правок (деплой, массовые замены).
- **Субагенты для разведки**: «use a subagent to выяснить …» — чтение кода идёт в отдельном контексте, в диалог возвращается только вывод; основной контекст не засоряется.
- **Продолжение работы**: `claude --continue` — последняя сессия в этой папке; `claude --resume` — выбор из списка; `claude --from-pr <N>` — найти сессию, из которой родился PR.
- **@-ссылки**: `@путь/файл` кладёт файл в контекст целиком, `@папка/` — листинг; по `@` работает автодополнение путей.
- **Пайпы (headless)**: `git log --oneline -20 | claude -p "суммаризуй"` — Claude как unix-утилита для скриптов и CI.
- **Задачи по расписанию**: Routines (claude.ai/code/routines — облако Anthropic, работает при выключенном Mac, триггеры по GitHub-событиям), scheduled tasks desktop-приложения (доступ к локальным файлам), GitHub Actions, `/loop` в открытой сессии.
